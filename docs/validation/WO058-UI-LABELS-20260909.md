## Présentation

Les cartes joueurs ne répètent plus « Titulaire » ou « Remplaçant ». Le numéro, le nom
et le poste restent affichés, ainsi que les sections « Titulaires » et « Remplaçants »
et leurs compteurs. Le HTML initial et le rafraîchissement JavaScript utilisent la même
présentation ; le classement des joueurs ne change pas.

Les sept groupes et les 51 noms statistiques observés dans le corpus local sont traduits
en français. Exemples : « Vue d’ensemble du match », « Possession du ballon »,
« Buts attendus (xG) », « Tirs cadrés », « Duels aériens », « Arrêts du gardien » et
« Coups de pied de but ». Les correspondances portent sur les noms sources connus ;
un nom nouveau, même associé à un code connu, reste affiché tel quel.

La présentation `Group` sépare le nom source, utilisé comme clé stable du panneau,
du libellé traduit. Deux groupes sources distincts ne sont pas fusionnés lorsqu’ils
partagent la même traduction. Les codes métriques, valeurs, ordre des observations,
périodes, parseurs, hashes et données persistées ne sont pas modifiés. Les templates
et le JavaScript affichent le même libellé, avec échappement du texte fournisseur.
